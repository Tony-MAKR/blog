## 一、网站有哪些板块

网站地址：**https://tony-makr.github.io/blog/**

| 板块 | 网址（在网站地址后面接上这一段） | 放什么内容 |
|---|---|---|
| 首页 | `/` | 文章列表，按时间从新到旧，每页 10 篇 |
| 生活随笔 | 文章内自动分类 | 日常记录、读书感想 |
| 技术笔记 | 文章内自动分类 | 学习工作中的技术与心得 |
| 标签页 | `/tags/` | 按标签汇总文章（如「随笔」「Markdown」） |
| 分类页 | `/categories/` | 按分类汇总文章 |
| 归档 | `/archives/` | 所有文章按年份、月份排成一条时间线 |
| 关于我 | `/about/` | 自我介绍、联系方式 |
| 订阅 | `/atom.xml` | RSS 订阅地址，别人可用阅读器订阅 |
| 搜索引擎地图 | `/sitemap.xml` | 给搜索引擎看的文章清单，自动生成 |

> 举例：归档页的完整地址是 https://tony-makr.github.io/blog/archives/

## 二、功能总览

**状态说明**：✅ 已能用了 ｜ ⏸️ 已配好但没开启 ｜ 📋 以后可以加

### 写作与阅读

| 功能 | 用大白话说 | 怎么实现的 | 状态 |
|---|---|---|---|
| 文章列表与分页 | 首页列出文章，超过 10 篇自动翻页 | Hexo 首页生成器，每页 10 篇 | ✅ |
| 文章页 | 点标题进入完整文章 | Hexo 页面模板 | ✅ |
| 分类 | 每篇文章归入一个分类，点分类看同类文章 | Hexo 分类功能 | ✅ |
| 标签 | 每篇文章可打多个标签，方便串联主题 | Hexo 标签功能 | ✅ |
| 归档 | 所有文章按年月排成时间线 | Hexo 归档页 | ✅ |
| 关于我 | 固定的自我介绍页 | `source/about/index.md` | ✅ |
| 摘要 | 首页只显示文章开头，点进去看全文 | 在文章里插入 `<!-- more -->` 标记 | ✅ |
| 站内搜索 | 网站右上角搜标题和正文 | 主题自带，数据来自 `search.json` | ✅ |
| 订阅（RSS） | 读者用阅读器订阅，你一发新文章他就收到 | `hexo-generator-feed` 插件 | ✅ |
| 字数与阅读时长 | 每篇文章显示多少字、大约读几分钟 | `hexo-wordcount` 插件 | ✅ |
| 文章目录 | 长文章右侧自动出现小目录，可跳转 | 主题自带 | ✅ |

### 视觉与排版

| 功能 | 用大白话说 | 怎么实现的 | 状态 |
|---|---|---|---|
| 深色 / 浅色模式 | 右上角按钮切换，晚上看不刺眼 | 主题自带，默认深色 | ✅ |
| 手机适配 | 手机上排版自动调整 | 主题自带响应式设计 | ✅ |
| 方舟风格界面 | 明日方舟罗德岛风格的配色与动效 | 主题 `arknights` | ✅ |
| 文章插图 | 文章里放图片 | 图片放 `source/img/`，文中写 `![](/img/图片名)`（系统会自动补全地址） | ✅ |
| 图片点击放大 | 点文章里的图片可放大查看 | lightgallery（文件已存进网站） | ✅ |
| 代码高亮 | 技术文章里代码自动上色，带一键复制 | Hexo 内置 highlight.js + 主题样式 | ✅ |
| 数学公式 | 文章里能写 $E=mc^2$ 这类公式 | `hexo-filter-mathjax`，生成网页时就画好 | ✅ |
| 流程图等图表 | 技术文章里能画流程图、时序图、甘特图 | mermaid（文章里没有图就不加载它） | ✅ |
| 提示框 | 文章里插入「提示 / 警告 / 成功」样式的方框 | 主题标签 `{% note %} {% warning %}` 等 | ✅ |
| 折叠内容 | 把一段内容默认藏起来，点击展开 | 主题标签 `{% hide %}` | ✅ |

### 互动与统计（第三步可开启）

| 功能 | 用大白话说 | 怎么实现的 | 状态 |
|---|---|---|---|
| 评论 | 读者在文章下留言 | Giscus：读者用 GitHub 账号留言，数据存在你自己仓库里，免费无广告 | 📋 |
| 访问统计 | 显示网站总访问量、每篇文章被看过多少次 | Vercount（国内服务，不用注册账号） | 📋 |
| 文章加密 | 给某篇文章设密码，别人要输入才能看 | 主题自带，在文章开头加 `password:` 即可 | ⏸️ |
| 打赏二维码 | 文章末尾显示收款码 | 主题自带，需自己放入二维码图片 | ⏸️ |
| 背景音乐 | 访客一进网站就自动播放音乐 | 主题自带，**默认已关闭**（会自动出声打扰访客） | ⏸️ |
| 友情链接卡片 | 文章里展示一组带图标的好友链接 | 主题标签 `{% linkcard %}` | ✅ |

## 三、技术方案（了解用，日常不用管）

| 项目 | 说明 |
|---|---|
| 网站生成工具 | **Hexo 8**（把文字文件「打印」成网页） |
| 主题 | **hexo-theme-arknights**（明日方舟罗德岛风格，作者 Yue-plus） |
| 代码托管 | **GitHub**，仓库 `https://github.com/Tony-MAKR/blog` |
| 网站托管 | **GitHub Pages**（免费，无服务器） |
| 自动发布 | **GitHub Actions**：内容一保存，1-2 分钟自动更新网站 |

### 两处针对国内的特别处理

主题默认从国外的免费资源库加载文件，实测国内访问要等 20 秒以上甚至超时。已做处理：

1. **图表库、图片放大库改为网站自带**
   文件已下载到 `source/lib/` 里，随网站一起发布，不再依赖国外服务。

2. **没用到就不加载**
   一篇文章里没有流程图时，不加载 2.7 MB 的图表库——纯文字文章打开很快。

这两项由 `scripts/localize-assets.js` 自动完成。

### 已知的小限制

- 主题的「网页无刷新切换」（pjax）**已关闭**。开启后点击链接不刷新整页，但容易让图表、统计、评论显示异常。关闭后点击链接是正常跳转，更稳定。
- 图标和背景图仍使用明日方舟官方的图片地址。国内访问很快（实测 1 秒内），但如果官方改地址，背景图可能失效，到时候可改为本地图片。
