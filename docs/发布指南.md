# L的博客 · 发布指南

> 这份文档教你**不用装任何软件**，直接在网页上写文章、改错别字。
> 每次保存后大约 1-2 分钟，网站自动更新。

---

## 〇、最重要的一条规则

**只修改 `source` 文件夹里的文件，其他文件夹一律不要动。**

其他文件夹是网站的「发动机舱」（配置、主题、脚本），动了可能导致网站打不开。
需要改动时，把需求告诉 Claude。

---

## 一、写一篇新文章

### 第 1 步：打开仓库

浏览器打开 **https://github.com/Tony-MAKR.github.io**

### 第 2 步：进入文章文件夹

点进 `source` → `_posts`，会看到两个文件夹：

- `life` —— 生活随笔
- `tech` —— 技术笔记

点进你要写的那一类。

### 第 3 步：新建文件

1. 点右上角 **Add file** → **Create new file**
2. 文件名填英文或拼音，**用连字符代替空格**，例如：
   - `my-first-trip.md`
   - `reading-notes-2026.md`
   > 文件名会成为网址的一部分，所以用英文/拼音。
   > 中文标题写在文件内容里（下一步），不受影响。

### 第 4 步：把下面的模板粘进去，然后改

```markdown
---
title: 这里写文章标题
date: 2026-09-16 20:00:00
categories:
  - 生活随笔
tags:
  - 随笔
---

这里写文章的开头一段，它会显示在首页上。

<!-- more -->

这里写正文，首页只显示上面那段。
```

**注意事项：**

- `title:` 后面的中文**不用加引号**也能用
- `date:` 是发布时间，格式是 `年-月-日 时:分:秒`
- `categories:` 只能填 `生活随笔` 或 `技术笔记`（想加新分类告诉 Claude）
- `tags:` 可以写多个，每行一个，前面加两个空格和一个 `-`
- `<!-- more -->` 是「首页显示到这里的截止线」，放在开头段之后

### 第 5 步：保存

拉到页面底部，点绿色按钮 **Commit changes**，再点一次确认。

**完成！** 大约 1-2 分钟后刷新你的网站，新文章就出现了。

## 二、改错别字 / 修改已有文章

1. 打开仓库，一层层点进 `source/_posts/life` 或 `tech`
2. 点文章文件名
3. 点右上角的**铅笔图标**（Edit this file）
4. 改完拉到页面底部 → **Commit changes** → 确认

想删除文章：点进文章文件 → 右上角 **...** → **Delete file** → 确认。

> ⚠️ 删除是不可恢复的，删之前先确认清楚。

---

## 三、在文章里插图片

### 第 1 步：上传图片

1. 打开仓库 → 点进 `source` 文件夹 → 点进 `img` 文件夹
2. 右上角 **Add file** → **Upload files**
3. 把图片拖进去（文件名建议用英文，例如 `2026-trip-01.jpg`）
4. 拉到底部点 **Commit changes**

### 第 2 步：在文章里引用

在文章里写：

```markdown
![图片说明](/img/2026-trip-01.jpg)
```

方括号里是图片说明（鼠标悬停时显示，也可以留空），圆括号里是图片地址，
格式固定为 `/img/文件名`。

**小提示**：图片直接点一下可以放大查看（这个功能已开启）。

## 四、Markdown 速查表（写文章用的「语法」）

只需记住这 5 条，足够写日常文章了：

| 你想写 | 就这样写 | 效果 |
|---|---|---|
| 小标题 | `## 这是标题` | 显示为**加粗大字号**的标题 |
| 加粗 | `**要强调的字**` | **要强调的字** |
| 列表 | `- 第一项`（每项一行，前面加 `- `） | • 第一项 |
| 链接 | `[点这里](https://网址)` | 点这里 |
| 图片 | `![说明](/img/图片名.jpg)` | 显示图片 |

**换行**：直接回车换行即可；想空出一行做段落分隔，就连按两次回车。

**写代码**（技术文章用）：用三个反引号把代码围起来，开头写上语言名：

````
```python
print("你好")
```
````

**写数学公式**：用一对美元符号包起来，例如 `$E = mc^2$`。

## 五、常见问题

### 保存后网站没变化？

- 等 1-2 分钟，构建需要时间
- 打开仓库的 **Actions** 标签页：
  - 显示**绿色对勾** ✅ = 发布成功，若页面还没变，按 `Ctrl+F5` 强制刷新
  - 显示**红色叉号** ❌ = 发布失败，把截图发给 Claude

### 网站打不开了 / 排版乱了？

多半是格式写错了。最常见的原因：

1. 文章开头 `---` 这两行被不小心删掉了
2. `categories:` 或 `tags:` 下面的缩进乱了（`- ` 前面要有**两个空格**）

把出错前改的内容告诉 Claude，很快能修好。

### 想加新分类？

告诉 Claude 要加什么分类，会一并处理好。

### 文章里的公式、流程图显示不出来？

- 公式：写成 `$公式$`（美元符号和公式之间**不要有空格**）
- 流程图：用 ` ```mermaid ` 开头的代码块

## 六、另一种更省事的方式

把内容（文字、图片）直接发给 Claude，说明：

- 想发在哪个分类下
- 标题和发布时间

Claude 会完成排版、配图、发布的全过程，你只需要等着看结果。

**两种方式可以混着用**，Claude 每次发布前会先同步你在网页上的改动，不会互相覆盖。
